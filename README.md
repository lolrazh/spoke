# Sonic Flow

Lightweight AI dictation app.

## Installation

### Windows

The Windows installer (`Sonic-Flow Setup.exe`) uses Squirrel.Windows for a seamless installation experience:

1.  **No Prompts:** When you run the setup file, you'll see a brief loading animation. There are no traditional setup steps asking for installation paths or options.
2.  **Silent Install:** The application installs itself automatically in the background to your user profile's local application data folder (usually `C:\Users\<YourUsername>\AppData\Local\sonic-flow\`).
3.  **Auto-Launch:** Once installed, the application will launch immediately.
4.  **Shortcuts:** Shortcuts will be created on your Desktop and/or Start Menu.

This method is designed for simplicity and enables smooth automatic updates in the future.
